# My Nand2Tetris Projects

This repository contains my implementations of the projects from the **Nand2Tetris** course.

The course teaches how to build a complete computer system from first principles, starting from logic gates up to a working operating system.

---

## Course Information

Created by the Hebrew University of Jerusalem  
Taught by Simon Schocken and Noam Nisan

## Goal

To fully implement the Nand2Tetris stack in Rust while deeply understanding how high-level code is executed on a real machine.
